## whoami

I build web and mobile applications end to end, from the backend to the interface, and I self-host most of what I ship on a NAS I administer myself: Docker, Traefik, reverse proxy, no managed platform.

Two of my apps run in production with real users. Before that, 14 months of apprenticeship at **Turtlewet** as a CMS developer: PrestaShop and WordPress e-commerce sites for clients, custom modules, a 1.7 to 8 migration and technical SEO. Earlier still, two months in a hospital cybersecurity team at **Elsan**, working on security audits and an internal anti-phishing awareness campaign.

I like problems that go all the way down: real-time state, offline sync, deployment, and the boring production details nobody writes tutorials about.
